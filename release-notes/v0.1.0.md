The first release of encode-score: a Linux x86-64 build that scores video encodes against their source on an NVIDIA GPU, every frame, with VMAF, CAMBI banding, PSNR, lasting texture, grain and color. It needs glibc 2.35 or newer and an NVIDIA driver for CUDA 13 (release 580 or newer; tested with 615), and nothing else: FFmpeg 9.0.2, dav1d 1.5.4 and libvmaf (from [our fork](https://github.com/wakamex/vmaf), with fixes to its CUDA motion and VIF) are built in. The README covers usage and what the score measures.

`encode-score-v0.1.0-ffmpeg-source.tar.gz` is FFmpeg's release tarball with the scripts that build it and link it in, which the LGPL asks to accompany the static build. Check a downloaded asset with:

```
gh attestation verify ASSET --repo wakamex/encode-score --signer-workflow wakamex/release-actions/.github/workflows/binary-release.yml
gh release verify-asset v0.1.0 ASSET --repo wakamex/encode-score
```
